# 接口与配置手册

所有接口均在 `/ai` 前缀下，返回 JSON（UTF-8）；流式接口为 SSE。系统未做登录拦截，未登录也可调用（会话归属"访客"）。

---

## 一、状态与诊断

### `GET /ai/status`

```json
{
  "enabled": true,
  "mode": "local",                       // local | remote
  "model": "本地规则引擎（离线兜底）",
  "baseUrl": "https://api.deepseek.com/v1",
  "embeddingEnabled": false,
  "localFallback": true,
  "lastError": null,
  "tools": [{ "name": "query_students", "title": "学生信息查询", "description": "...", "parameters": {...} }],
  "knowledgeDocs": 9,
  "knowledgeChunks": 20,
  "stats": { ... },
  "user": "张教务"
}
```

### `POST /ai/breaker/reset`

清除远程模型熔断状态并重试。
返回：`{ "mode": "remote", "model": "deepseek-chat" }`

### `GET /ai/tools`

工具清单（含 JSON Schema 参数定义），用于核对工具能力。

## 二、对话

### `POST /ai/chat/stream`（SSE 流式，推荐）

请求体：

```json
{ "conversationId": 12, "message": "查一下张三的情况", "scene": "assistant", "newConversation": false }
```

- `conversationId` 为空或 `newConversation=true` 时新建会话；
- `scene` 取值：`assistant`（默认）/ `dashboard` / `warning` / `knowledge` / `sql`，影响提示词的场景约束。

**事件协议**（`event:<name>\ndata:<json>\n\n`）：

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `meta` | `{conversationId, scene, question, mode?, model?}` | 会话与模型元信息 |
| `step` | `{id, tool, title, args, status, summary, error, durationMs, render, data, chart}` | 工具步骤；`status=running/success/failed`，同一 `id` 会推送两次（开始与结束） |
| `delta` | `{text}` | 回答增量文本 |
| `citations` | `{items:[{title, category, snippet, score}]}` | 知识库引用 |
| `done` | `{conversationId, messageId, mode, model, toolRounds, steps, promptTokens, completionTokens, elapsedMs}` | 结束 |
| `error` | `{text}` | 异常 |

curl 示例（Windows PowerShell）：

```powershell
curl.exe -N -X POST http://localhost:8080/ai/chat/stream `
  -H "Content-Type: application/json" `
  -d "{\"message\":\"各班平均分对比\",\"scene\":\"assistant\",\"newConversation\":true}"
```

### `POST /ai/chat`（非流式，便于验收/自动化）

同一套 Agent 逻辑，返回一次性结果：

```json
{
  "conversationId": 13, "mode": "local", "model": "...",
  "content": "（Markdown 正文）",
  "steps": [ ... ],
  "citations": [ ... ],
  "toolRounds": 1, "promptTokens": 0, "completionTokens": 0, "elapsedMs": 128
}
```

### 会话历史

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/ai/conversations?limit=30` | 会话列表（注意是 POST） |
| GET | `/ai/conversations/{id}` | 会话详情 + 消息列表（含 tool_results / citations JSON） |
| DELETE | `/ai/conversations/{id}` | 删除会话 |

## 三、主动洞察、预警与画像

### `POST /ai/insight`

跑一遍 `stats_overview` + `analyze_scores` + `risk_warning`，再做数据质量检查，产出管理洞察。

```json
{
  "mode": "local",
  "model": "...",
  "overall": "学籍数据整体平稳，1 条待审异动是当前主要待办事项。",
  "points": [{ "title": "成绩数据覆盖", "detail": "4/10 名学生存在成绩记录，覆盖率 40%…", "level": "warning", "evidence": "有成绩学生 4 / 总数 10" }],
  "facts": {
    "metrics": [{ "label": "学生总数", "value": 10, "unit": "人" }],
    "byDept": [{ "name": "电子与信息工程学院", "value": 8 }],
    "byGender": [...], "byStatus": [...],
    "classScores": [{ "name": "计算24-1", "avgScore": 150, "passRate": 100 }],
    "riskMetrics": [{ "label": "高风险", "value": 0, "unit": "人" }],
    "riskRows": [...],
    "studentTotal": 10, "studentsWithScore": 4, "pendingChange": 1, "abnormalScore": 3
  },
  "generatedAt": "2026-10-18 15:20:31"
}
```

`level` 取值：`info` / `warning` / `danger`（前端据此选图标与配色）。

### `POST /ai/warning-advice`

请求：`{ "level": "all|high|medium|low", "limit": 20 }`

```json
{
  "mode": "local",
  "items": [{ "stuId": "2023002", "stuName": "李四", "level": "medium", "advice": "…", "reasons": "…" }],
  "overall": "建议按风险等级分层处置…",
  "rows": [ ... ]                       // 规则引擎原始预警行
}
```

### `POST /ai/students`

等价于 `query_students` 工具（服务端筛选）。请求体支持：`keyword`、`className`、`major`、`dept`、`status`、`gender`、`limit`。

返回 `ToolResult`：`{ tool, title, render:"table", summary, data:{columns, rows, total}, chart, hints, durationMs }`

### `POST /ai/students/profile`

请求：`{ "stuId": "2023001" }` 或 `{ "name": "张三" }`

```json
{
  "mode": "local", "model": "...", "success": true,
  "summary": "张三（2023001），计算24-2，共 2 条成绩，平均分 82.75",
  "profile": { "render": "profile", "data": { "basic": {...}, "scoreSummary": [...], "scores": [...], "rewards": [...], "changes": [...], "archiveCount": 0 } },
  "comment": "张三（2023001）…学业状态良好…",
  "suggestions": ["保持关注", "建议辅导员在本周内…"],
  "riskLevel": "low", "riskReasons": "无明显学业风险", "riskSuggestion": "保持关注",
  "generatedAt": "2026-10-18 15:22:10"
}
```

### `POST /ai/tool/{name}`

工具直连调试台：`name` 为工具名，请求体即工具参数。

```powershell
curl.exe -X POST http://localhost:8080/ai/tool/risk_warning -H "Content-Type: application/json" -d "{\"level\":\"high\",\"limit\":10}"
```

## 四、自然语言取数（NL2SQL）

### `POST /ai/sql`

请求：`{ "question": "统计各院系的学生人数" }`

成功：

```json
{
  "mode": "local",
  "success": true,
  "question": "统计各院系的学生人数",
  "sql": "SELECT COALESCE(d.dept_name,'未分配') AS \"院系\", COUNT(*) AS \"学生人数\" FROM student s LEFT JOIN \"class\" c ON s.class_id = c.class_id …",
  "explanation": "按院系统计学生人数",
  "columns": ["院系", "学生人数"],
  "rows": [{ "院系": "电子与信息工程学院", "学生人数": 8 }],
  "total": 3, "truncated": false, "elapsedMs": 9
}
```

未通过安全校验：

```json
{ "mode": "local", "success": false, "sql": "…", "message": "生成的 SQL 未通过安全校验：语句包含不允许的关键字：update" }
```

本地模板可识别的表达（无大模型时）：各院系人数、各班级人数、各班平均分与及格率、按课程平均分、性别分布、各专业人数、奖励明细、待审核异动。配置大模型后不再受此限制。

## 五、制度知识库（RAG）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ai/knowledge` | `{ list:[{id,title,category,tags,source,chunk_count,create_time,preview}], count, chunks, embeddingEnabled }` |
| GET | `/ai/knowledge/{id}` | 文档详情（含 content） |
| POST | `/ai/knowledge` | 新增/更新。体：`{id?, title, category, tags, source, content}`（也支持 `paragraphs: []` 数组）；返回 `{success, id, count}` |
| DELETE | `/ai/knowledge/{id}` | 删除并清理片段 |
| POST | `/ai/knowledge/reindex` | 重建全部索引，返回 `{success, docs, chunks}` |
| POST | `/ai/knowledge/reset` | 恢复内置示例语料（9 篇） |
| POST | `/ai/knowledge/search` | 检索测试。体：`{query, topK}`；返回 `{query, hits:[{docId,title,category,source,content,score}]}` |

保存后会自动对该文档重新切分并重建索引，立即参与问答检索。

## 六、大模型配置

配置文件：`src/main/resources/application.yml` 的 `ai:` 段。

```yaml
ai:
  enabled: true
  mode: auto                 # auto（有 key 走远程，无 key 走本地）| remote | local
  base-url: https://api.deepseek.com/v1
  api-key: ${AI_API_KEY:}    # 建议用环境变量注入，不要写进仓库
  model: deepseek-chat
  embedding-model: ${AI_EMBEDDING_MODEL:}   # 可选：bge-m3 / text-embedding-3-small
  temperature: 0.3
  max-tokens: 1600
  timeout-seconds: 90
  max-tool-rounds: 5         # Agent 最多工具轮数
  sql-max-rows: 200          # NL2SQL 返回行数上限
  sql-timeout-seconds: 8     # 单条查询超时
  rag-top-k: 4               # 检索片段数
  org-name: 示例大学          # 提示词中的学校名
```

### 切换模型示例

| 供应商 | base-url | model |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |

### 启动方式

```powershell
# 方式一：环境变量（推荐）
$env:AI_API_KEY = "sk-xxxx"
.\mvnw.cmd spring-boot:run

# 方式二：临时强制本地模式（答辩演示断网场景）
$env:AI_MODE = "local"      # 或直接改 application.yml 的 ai.mode
```

### 验证是否生效

```powershell
curl.exe http://localhost:8080/ai/status
# "mode":"remote" 且 "embeddingEnabled" 按需为 true 即为已接入
```

> 注意：`ai.mode=auto` 且未配置 key 时，`/ai/status` 返回 `mode=local`，AI 回答会以"当前为本地推理模式…"开头，这是设计行为，不是故障。

## 七、数据库对象（自动创建）

`SchemaInitializer` 在启动时以 `CREATE TABLE IF NOT EXISTS` 幂等创建：

| 表 | 用途 |
| --- | --- |
| `ai_conversation` | 会话（标题、场景、归属用户、时间） |
| `ai_message` | 消息（角色、内容、工具链 JSON、引用 JSON、模式、模型、token） |
| `ai_knowledge` | 制度文档 |
| `ai_knowledge_chunk` | 文档片段与可选向量 |

原有业务表**不做任何结构变更**；所有查询均为只读。
